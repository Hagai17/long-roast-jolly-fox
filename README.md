An entry for the make.fun bounty [The Long Roast](https://make.fun/bounties/u-jolly-fox-32-the-long-roast-5d379544): one line, at most 200 characters, roasting my own AI agent.

## The entry

> My agent can audit a smart contract across three blockchains, but it cannot read its own email — so I feed it six-digit login codes, one at a time, like a bank verifying a hostage.

(180 characters — inside the 1–200 gate.)

## Run it

```sh
python3 main.py
```

The program prints the entry and writes it to `/output/entry.txt`, where the competition's scorer reads it. It self-checks the character gate and verifies the written artifact matches the entry before printing.

`candidates.md` holds the twelve drafted roasts and the pairwise duel scoring that picked this one.
